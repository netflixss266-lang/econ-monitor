# ระบบบัญชีผู้ใช้ — รอบที่ 1

โครงทั้งหมดเขียนไว้แล้วและกดใช้งานได้ในเครื่อง เหลือขั้นตอนที่ต้องทำในบัญชี Supabase
ของเจ้าของเว็บเท่านั้น (ผมทำแทนไม่ได้ เพราะต้องสมัครและกรอกรหัสผ่านในบัญชีคุณเอง)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร |
|---|---|
| `schema.sql` | ตาราง `profiles` กับ `login_events` สิทธิ์รายแถว และงานลบข้อมูลเมื่อครบ 90 วัน |
| `functions/log-login/index.ts` | Edge Function อ่าน IP จริงจาก header แล้วบันทึกลง `login_events` |
| `auth.js` | ตัวกลางระหว่างหน้าเว็บกับระบบบัญชี มีสองร่าง: ทดลอง กับ Supabase จริง |
| `account.html` | หน้าเข้าสู่ระบบ / สมัคร / ลืมรหัสผ่าน และหน้าประวัติการเข้าใช้ |
| `privacy.html` | นโยบายความเป็นส่วนตัว ฉบับร่าง |

## ลองดูหน้าตาก่อนได้เลย

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000/auth/account.html` — จะขึ้นแถบ "โหมดทดลอง"
ข้อมูลทั้งหมดอยู่ในเบราว์เซอร์เครื่องนั้น ไม่ส่งออกไปไหน และ IP ที่เห็นเป็นเลขสมมติ

ร่างทดลองจะทำงานเฉพาะบน `localhost` เท่านั้น ถ้าเปิดจากเว็บจริงหน้าจะขึ้นว่ายังไม่เปิดใช้งาน
และปิดช่องกรอกไว้ กันคนเข้าใจผิดว่าสมัครกับเว็บจริงไปแล้ว

## ต่อของจริง — 5 ขั้น

1. **สร้างโปรเจกต์** ที่ [supabase.com](https://supabase.com) (เข้าด้วยบัญชี GitHub ได้)
   เลือก region **Singapore** จะใกล้ผู้ใช้ไทยที่สุด
2. **สร้างตาราง** — เปิด SQL Editor วางไฟล์ `schema.sql` ทั้งไฟล์แล้วกด Run
3. **ตั้งค่าอีเมล** — Authentication → Providers → เปิด Email
   และเปิด **Confirm email** ไว้ (บังคับยืนยันอีเมลก่อนใช้งานครั้งแรก)
4. **ติดตั้ง Edge Function**

   ```bash
   supabase functions deploy log-login
   ```

   ตัว `SUPABASE_URL` กับ `SUPABASE_SERVICE_ROLE_KEY` Supabase ใส่ให้อัตโนมัติอยู่แล้ว
   เพิ่มเองอีกตัวเดียวคือ `SITE_ORIGIN` = `https://netflixss266-lang.github.io`
5. **ใส่คีย์ในหน้าเว็บ** — เอา Project URL กับ anon key จาก Project Settings → API
   มาใส่ใน `CONFIG` ที่หัวไฟล์ `auth.js` แล้วเสร็จ ตัว `auth.js` จะสลับไปใช้ Supabase
   ให้เองอัตโนมัติเมื่อเห็นว่ามีค่าแล้ว

### เรื่องคีย์

- **anon key** ออกแบบมาให้เปิดเผยได้ ใส่ในโค้ดหน้าเว็บและ commit ได้ตามปกติ
  ความปลอดภัยมาจากสิทธิ์รายแถวในฐานข้อมูล ไม่ได้มาจากการซ่อนคีย์
- **service_role key** ข้ามสิทธิ์ทุกอย่างในฐานข้อมูล
  ต้องอยู่ใน Edge Function เท่านั้น **ห้าม commit และห้ามส่งให้ใครทั้งสิ้น**

## เปิด pg_cron ให้ลบข้อมูลอัตโนมัติ

Database → Extensions → เปิด `pg_cron` แล้วรันใน SQL Editor

```sql
select cron.schedule('purge-login-events', '17 3 * * *',
                     $$select public.purge_old_login_events()$$);
```

ข้อนี้ข้ามไม่ได้ เพราะนโยบายความเป็นส่วนตัวประกาศไว้ว่าเก็บ 90 วัน
ถ้าไม่ได้ตั้ง ข้อมูลจะค้างอยู่ตลอดกาลและกลายเป็นทำไม่ตรงกับที่ประกาศ

## ยังไม่ได้ทำในรอบนี้

- ยังไม่มีลิงก์เข้าหน้าบัญชีจากหน้าเว็บหลัก — ตั้งใจไว้แบบนั้นจนกว่าจะต่อของจริงเสร็จ
- จำกัดจำนวนครั้งที่ลองรหัสผ่าน (Supabase มีขั้นพื้นฐานให้ ถ้าต้องการเข้มกว่านั้น
  ต้องเขียนเพิ่มใน Edge Function)
- ซิงก์รายการโปรดกับอินดิเคเตอร์ขึ้นบัญชี — ตารางเตรียมคอลัมน์ไว้แล้ว รอรอบที่ 3
- ยืนยันสองชั้น และแจ้งเตือนเมื่อเข้าใช้จากประเทศใหม่ — รอบที่ 4
