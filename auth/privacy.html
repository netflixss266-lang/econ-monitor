The Tribune Privacy Notice
ฉบับร่าง — เขียนไว้ให้ครบตามที่ระบบเก็บจริง ยังไม่ได้ประกาศใช้ และควรให้นักกฎหมายตรวจอีกรอบก่อนเปิดรับสมาชิกจริง

ปรับปรุงล่าสุด: ยังไม่ประกาศใช้

เก็บอะไรบ้าง

เว็บนี้อ่านข่าวได้โดยไม่ต้องสมัครสมาชิก ถ้าไม่สมัคร เราไม่เก็บข้อมูลส่วนบุคคลใดๆ ของคุณเลย เมื่อคุณสมัครและเข้าสู่ระบบ เราจะเก็บข้อมูลต่อไปนี้

  • อีเมล — ใช้เป็นชื่อบัญชี ยืนยันตัวตน และส่งลิงก์ตั้งรหัสผ่านใหม่
  • รหัสผ่าน — เก็บเป็นค่าที่ผ่านการแฮชแล้วเท่านั้น เราไม่มีทางอ่านรหัสผ่านจริงของคุณได้ และไม่มีใครในทีมเห็นรหัสผ่านของคุณ
  • ประวัติการเข้าใช้ — วันเวลา ผลลัพธ์ (สำเร็จ/ไม่สำเร็จ) หมายเลข IP รหัสประเทศ และข้อมูลเบราว์เซอร์กับระบบปฏิบัติการที่ใช้
  • การตั้งค่าของคุณ — รายการสินทรัพย์โปรดและอินดิเคเตอร์ที่เลือกไว้

เก็บ IP ไปทำอะไร

หมายเลข IP ถือเป็นข้อมูลส่วนบุคคลตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล เราจึงระบุให้ชัดว่าใช้ทำอะไรบ้าง

ใช้ทำอะไรฐานการประมวลผลเก็บนานแค่ไหน
ตรวจจับการพยายามเดารหัสผ่าน และแจ้งเตือนคุณเมื่อมีการเข้าใช้จากที่ผิดปกติ ประโยชน์โดยชอบด้วยกฎหมาย เพื่อความปลอดภัยของบัญชีคุณเอง 90 วัน
แสดงประวัติการเข้าใช้ให้คุณตรวจสอบเองในหน้าบัญชี การให้บริการตามที่คุณร้องขอ 90 วัน
สถิติภาพรวมว่าผู้อ่านมาจากประเทศใด ประโยชน์โดยชอบด้วยกฎหมาย — ใช้เลข IP แบบตัดท้ายซึ่งชี้ตัวบุคคลไม่ได้ ไม่จำกัด (ไม่ระบุตัวตนแล้ว)

เมื่อครบ 90 วัน ระบบจะลบประวัติการเข้าใช้ที่มีหมายเลข IP เต็มโดยอัตโนมัติ เราไม่ใช้ข้อมูลของคุณเพื่อการตลาด ไม่ขาย และไม่ส่งต่อให้บุคคลที่สาม

ใครเข้าถึงข้อมูลได้

  • ตัวคุณเอง ผ่านหน้าบัญชีของคุณ
  • ผู้ดูแลเว็บ เท่าที่จำเป็นต่อการแก้ปัญหาและดูแลความปลอดภัย
  • ผู้ให้บริการโครงสร้างพื้นฐาน (Supabase สำหรับฐานข้อมูลและระบบบัญชี และ GitHub Pages สำหรับหน้าเว็บ) ในฐานะผู้ประมวลผลข้อมูลตามสัญญา

สิทธิของคุณ

  • ขอดูข้อมูลทั้งหมดที่เรามีเกี่ยวกับคุณ
  • ขอแก้ไขข้อมูลที่ไม่ถูกต้อง
  • ขอลบบัญชีและข้อมูลทั้งหมด — เมื่อลบบัญชี ข้อมูลทุกอย่างรวมถึงประวัติการเข้าใช้จะถูกลบตามไปด้วย
  • คัดค้านการประมวลผล หรือขอให้ระงับการใช้ข้อมูลชั่วคราว
  • ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล หากเห็นว่าเราทำไม่ถูกต้อง

คุกกี้

เราใช้คุกกี้เพียงตัวเดียวคือคุกกี้ที่ทำให้คุณยังอยู่ในระบบหลังเข้าสู่ระบบแล้ว ไม่มีคุกกี้เพื่อการโฆษณาหรือการติดตามข้ามเว็บ

ติดต่อ

เรื่องข้อมูลส่วนบุคคล ติดต่อผู้ดูแลเว็บได้ที่อีเมลที่แจ้งไว้หน้าติดต่อ เราจะตอบกลับภายใน 30 วันตามที่กฎหมายกำหนด
